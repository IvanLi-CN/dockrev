# AppShell Navigation

Desktop navigation supports the normal expanded shell, the compact icon-only shell, and a detail layout with a dedicated service tree rail. The header uses the same column boundary as the route workspace: primary navigation for standard pages, and primary navigation plus the service rail for detail pages. Identity moves into the desktop navigation footer and remains a compact topbar control on mobile.
