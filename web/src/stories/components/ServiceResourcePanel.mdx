`ServiceResourcePanel` 把实时状态提升到头部 badge，并把指标切换与时间窗口整理成同一工具栏，同时保留 SSE 实时状态与历史趋势图逻辑；离线时则退化为本地缓存只读态。
</Description>

## 关注点
- 顶部 Hero 会展示实时状态 badge、窗口/样本/最近更新时间 facts。
- `Tabs` 负责 CPU / 内存 / 网络 / 磁盘 I/O / PIDs 的指标切换，`ToggleGroup` 负责 15m / 1h / 6h 时间窗口。
- CPU、内存、网络与磁盘 I/O 将每个原始样本保持到下一次采样，使用 right-continuous 阶梯表达变化；连续指标仅在阶梯拐角加极小圆角，不平均数值、不生成斜线。PIDs 保持严格直角阶梯。
- 单序列保留弱面积辅助趋势扫读，双序列维持纯线；每条曲线保留最新样本锚点。
- Story 使用 mock API，覆盖默认、空数据、监控关闭、流错误、离线缓存只读态，以及高波动与缺口数据。
