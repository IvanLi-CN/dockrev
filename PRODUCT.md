# Product

## Register

product

## Users

Dockrev is for self-hosting operators, homelab maintainers, and small infrastructure owners who manage Docker Compose services directly. They use it during routine maintenance, update review, incident recovery, and quick checks from a trusted admin surface.

## Product Purpose

Dockrev helps operators discover Docker Compose services, see update and resource state, preview changes, apply updates, recover from failures, and reach service launch targets without turning maintenance into a manual checklist. Success means the operator can scan, decide, act, and verify from one calm interface.

## Brand Personality

Calm, exact, operationally confident. The interface should feel like a quiet command console: dense enough for repeated work, precise enough for risky actions, and restrained enough to stay readable during late maintenance windows.

## Anti-references

- Marketing landing-page hero.
- Oversized decorative cards.
- Generic dark-blue SaaS dashboard.
- Glassmorphism as default.
- Neon cyberpunk styling.
- Fake metrics or decorative status.
- Modal-first flows for routine decisions.
- Dense but unstructured admin tables.

## Design Principles

- Scan first: the first read should reveal service grouping, state, and action priority.
- Keep state honest: show real data, stale state, disabled state, and unknown state without pretending.
- Put actions near evidence: update, scan, and navigation controls must live beside the facts that justify them.
- Stay compact and repeatable: controls should support repeated operational work without oversized chrome.
- Use restrained confidence: visual polish should clarify status and hierarchy, not perform.

## Accessibility & Inclusion

Dockrev should target WCAG AA contrast for core text and controls, visible keyboard focus, color plus text for operational status, reduced-motion support, and usable layouts from 320px wide mobile screens through dense desktop dashboards.
